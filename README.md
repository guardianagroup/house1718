# HOUSE 1718

Web institucional de [house1718.com](https://house1718.com).

Firma en Bocagrande (Torre Empresarial Prodegi, plantas 17 y 18) orientada a reducir el coste operativo de hoteles, restaurantes, residencias de alto consumo, oficinas, clínicas y comercios.

## Publicar

1. En el repositorio: Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`.
2. En el DNS del dominio `house1718.com`, un registro `A` o `CNAME` según indique GitHub Pages.
3. El archivo `CNAME` de este repo ya apunta a `house1718.com`.
