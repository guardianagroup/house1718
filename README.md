# HOUSE 1718

Web institucional de [www.house1718.com](https://www.house1718.com/).

Consultoría de costos, operación y rentabilidad para negocios y proyectos en Colombia, con sede en Bocagrande, Cartagena de Indias. La web presenta el enfoque, la metodología de análisis algorítmico y simulación de escenarios, el proceso de trabajo y los canales de contacto.

## Publicar

1. En el repositorio: Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`.
2. En el DNS del dominio `house1718.com`, un registro `A` o `CNAME` según indique GitHub Pages.
3. El dominio personalizado de GitHub Pages es `www.house1718.com`; el dominio raíz redirige a esa dirección.
4. Mantener activada la opción **Enforce HTTPS** en GitHub Pages.
